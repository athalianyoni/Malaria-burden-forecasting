# GitHub setup

Suggested repository name:

`malaria-burden-forecasting`

Suggested short description:

`Weekly malaria burden forecasting and uncertainty quantification using surveillance and weather data, developed as a Peru proof of concept for future local hospital adaptation in Zimbabwe.`

## Recommended visibility

Use **Public** if all uploaded files are de-identified and you have the right to share them. Do not upload confidential hospital data or patient identifiers.

## Files to upload

Upload the contents of this folder to the repository root.

If you want the exact exploratory notebook to be visible as well, add your local `MalariaModel.ipynb` after checking that:

1. no private patient information appears in any cell or output;
2. no local passwords, API keys or tokens are present;
3. file paths do not expose sensitive information;
4. cells are in a logical order;
5. old failed experiments that make the notebook unreadable are either explained or removed;
6. final outputs match the README.

A suitable notebook name would be:

`malaria_forecasting_analysis.ipynb`

## Create the repository manually

1. Sign in to GitHub.
2. Select **New repository**.
3. Name it `malaria-burden-forecasting`.
4. Add the short description above.
5. Choose **Public** if appropriate.
6. Do not initialize with another README if you plan to upload this prepared README.
7. Create the repository.
8. Upload the files/folders from this package.
9. Commit the files.

Your final URL will follow this pattern:

`https://github.com/YOUR-USERNAME/malaria-burden-forecasting`
